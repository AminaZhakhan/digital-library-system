# Console-based Digital Library & E-Reader System

A multi-user management system designed to handle digital content consumption and creation, built with Java and modern OOP principles.

## 🚀 Key Features
- **Multi-role Access Control:** Distinct functionalities for Readers (browsing, progress tracking) and Publishers (content management).
- **Gamification:** Real-time achievement and reading streak notification system.
- **State-based Navigation:** Interactive CLI with a robust menu state machine for seamless UX.

## 🛠 Tech Stack & Design Patterns
- **Language:** Java (JDK 17+)
- **Data Management:** Java Collections Framework for metadata and user progress.
- **Design Patterns:**
  - **Factory Pattern:** Decoupled object creation for various user roles and book types.
  - **Observer Pattern:** Implemented for the notification system to track streaks in real-time.
